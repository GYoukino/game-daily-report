GitHub 配置教程 · 小白版

照着做两件事，以后你电脑不用开、NAS 不用开，每天上午 10 点自动出日报

仓库：github.com/GYoukino/game-daily-report
日报网页：GYoukino.github.io/game-daily-report

先花 30 秒搞懂要做什么

GitHub 现在要帮你在云端跑抓取程序，但它缺两样东西：

  1. 飞书机器人的钥匙——不然它没法把日报推到你的飞书群
  2. 写文件的权限——不然它跑完的日报存不回仓库

下面是这两件事的精确点击路径，全程不用敲命令，大约 5 分钟。

1把飞书钥匙交给 GitHub

做一次就行，之后永久有效

① 先从你电脑上把钥匙复制出来

打开这个文件（右键 → 用记事本打开）：
D:\WorkBuddy工作任务\技能安装\game-activity-monitor\secrets.local.toml

里面你会看到这样的两行：

webhook = "https://open.feishu.cn/open-apis/bot/v2/hook/一长串字母数字"
secret = "另一串密钥"

把引号里面的内容分别复制出来（Ctrl+C）， 先粘贴到记事本备用，一共两串。

为什么要这一步？ 这把钥匙原来明明写在 config.toml 里， 但那个文件会上传到公开仓库，等于把钥匙挂在大门口。所以昨天我把它搬进了这个 不会被上传的文件里。GitHub 那边也需要同一把钥匙，你得手动递一次。

② 到 GitHub 网页上填进去

打开仓库首页，按这个顺序点：

Settings（右上角） → Secrets and variables → Actions → New repository secret
注意别走错：Secrets and variables 在左边侧栏里，不是顶上的标签页。 点开后要再点一下 Actions，才会看到新建按钮。

点绿按钮后填两栏，做两次（先 WEBHOOK，再 SECRET）：

Name 填这个（照抄）Secret 粘贴
FEISHU_WEBHOOK刚才复制的第 1 串（https:// 开头那行）
FEISHU_SECRET刚才复制的第 2 串
最容易出错的地方：名字必须一模一样，全大写、带下划线。 写成 feishu_webhook 或多了个空格，后面就会静默失败——不报错，但收不到消息。

③ 确认填对了

填完列表中应该出现两条记录，形如：

FEISHU_WEBHOOK      Updated now
FEISHU_SECRET       Updated now
看不到内容是不是填错了？ 不是。GitHub 出于安全考虑， 密钥存进去之后连你自己都看不到明文了，只能删掉重填。这是正常的保护措施。

2给它一个写文件的权限

漏了这步，日报生成了却存不回去

Settings → Actions → General → 往下滚到 Workflow permissions

把选项从默认的 Read repository contents 改成：

● Read and write permissions

然后点那一小块区域右下角的绿色 Save 按钮。

这步 90% 的人会漏。 因为页面上的 Save 按钮位置比较隐蔽， 改完选项一定要真的点到 Save。没保存 = 等于没改。

3立刻手动跑一次，验证成功

现在验证过，明天就不用操心了

仓库顶上的 Actions 标签页 → 左侧列表找 每日游戏前瞻日报 → 右边 Run workflow ▾ → 点绿色 Run workflow

点完之后等一两分钟，列表里会冒出一条正在转圈的运行记录，点进去能看到实时日志。

🔒关于隐私：现在谁能看到？

先说结论：仓库是公开的，但里面没有任何你的私人信息

我把全部 31 次历史提交从头到尾扫了一遍，结果如下：

检查项结果
飞书 webhook / 签名密钥没有泄露（已移出公仓库）
你的真实姓名 / 邮箱没有泄露（提交身份是 game-monitor@localhost 这个假身份）
电脑本地路径（如 D 盘真实目录）没有出现
NAS 地址、内网 IP没有出现
仓库里剩下的是什么抓取脚本源码 + 每天的游戏前瞻资讯（原神、星铁、方舟等 9 款游戏的公开官方信息）

唯一对外可见的你的个人信息，是你的 GitHub 用户名 GYoukino—— 但这个在 GitHub 上本来就是公开的，不属于泄露。

一句话理解风险： 外面的人看到的是一个「每天自动整理游戏资讯」的小项目， 就像你在网上分享的一个小工具。他知道你在玩/关注原神、星铁、明日方舟这些， 但拿不到你的飞书、威胁不到你的账号、也进不了你的电脑或 NAS。

想改成只有自己能看？可以，但有个代价

关键限制： GitHub 免费账户的网页托管（Pages）只对公开仓库开放。 仓库一旦设为私有，GYoukino.github.io/game-daily-report 这个网页立刻打不开， 除非升级到付费版 Pro（大约每月 4 美元）。
方案网页还能看吗费用适合谁
① 保持公开
推荐		 能，一切照旧免费 反正没有敏感内容，省心
② 转私有 + 只推飞书 不能免费 能接受只在飞书里看日报的人
③ 转私有 + NAS 上开网页
你的强项		 能，但只有家里网络或连 VPN 时免费 你已经有群晖了，装个 Web Station 把 daily 目录挂出去就行
④ 转私有 + 升 Pro 能，和现在一样约 ¥30/月 愿意花钱买省事

如果确定要转私有（方案 ②③④）

Settings → 页面最底部 Danger Zone → Change visibility → Make private

系统会让你手打一遍仓库名确认，照着输 GYoukino/game-daily-report 即可。

转私有后还有一件事要跟着改： NAS 上那个归档容器现在是用公开地址拉取的，私有仓库它拉不动，会变成空转。 需要在 GitHub 再办一张「通行证」（Personal Access Token）， 然后把容器配置里的地址改成带通行证的。这一步做完告诉我，我给你具体的改法——或者你就先维持公开，省掉这件事。
