# 游戏前瞻资讯资料来源清单

> 版本 v1.1 · 编制日期 2026-10-22 · 适用范围：游戏前瞻资讯汇总（前瞻直播/发布会、版本前瞻、限时兑换码、线下联动、周边上新、快闪店、漫展展会）
>
> 用途：为 game-activity-monitor 提供数据源选型依据。本文档为活文档，随 `config.toml` 接入情况同步更新，建议每季度复查标注「受限 / 不可行」的来源（风控政策变化快）。
> 注：表中不逐一列出接口地址，具体 URL/参数以接入时实测为准；标注「待验证」的来源建议接入前先探测。
>
> **v1.1 变更（2026-10-22）**：按项目重构要求，数据源原则改为**只采官方机构与官方渠道**——
> ① 移除「资讯聚合站与 Wiki 数据库」全部接入（原 4 个 18183/7724 兑换码页已下线，对应 `code_site` 采集器删除）；
> ② 新增展会与线下活动官方：BilibiliWorld（会员购官方票务接口）、TGA、gamescom、Summer Game Fest；
> ③ 新增电商与周边平台：哔哩哔哩会员购（开放票务接口，无需登录）；
> ④ 补记 ChinaJoy / CP 漫展 / 天猫旗舰店的实测结论（均受限，暂不接入）。

## 三、可信度分级与使用规则

| 级别 | 定义 | 典型来源 |
|------|------|---------|
| **S** | 官方一手发布 | 游戏官网/官微/官号、Steam 新闻、展会主办方 |
| **A** | 权威二手 | 大型平台官方渠道、专业媒体通稿、官方 Wiki、行业协会公示 |
| **B** | 专业垂直 | 垂直游戏媒体、知名资讯聚合站、数据库 API |
| **C** | 线索级 | UGC、自媒体、热搜榜、小道消息 |

**使用规则（已内置于 classifier.py / forward_report.py）：**
1. 前瞻三要素（时间、地点/入口、规则）**只采用 S/A 源**；B 源可作补充；C 源不得作为唯一来源。
2. 兑换码**只采官方渠道**：仅官网/官方直播发布的码可入日报，并标注"以游戏内实际兑换结果为准"；第三方资讯站汇总码不再采集（v1.1 起）。
3. 来源冲突时以官方最新公告为准，并在日报中标注来源。
4. 每条资讯必须标注来源与时效性（起止/截止日期）。

## 五、接入技术要点

1. **接入优先级**：官方 API / RSS ＞ 静态 JSON ＞ HTML 解析 ＞ 浏览器自动化（成本与维护量递增）。
2. **抓取礼仪**：遵守 robots.txt；声明 UA；请求间隔 ≥ 2-5 秒；失败指数退避；只抓公开内容，不抓登录后数据与个人信息。
3. **签名与凭证集中管理**：B站 WBI（密钥每日轮换）、微博 Cookie（约 30 天有效）等易失效凭证建议经 RSSHub 自建实例统一收口，避免散落在业务代码里。
4. **去重**：URL 签名 + 标题指纹 + 内容 hash（项目 storage.py 已实现）。
5. **时效性解析**：从正文提取"截止/失效/开启"日期（classifier.py 已实现），过期自动标灰。
6. **合规红线**：仅采集公开数据；控制频率避免影响对方服务；日报中保留来源署名；商用场景需另行评估授权。
